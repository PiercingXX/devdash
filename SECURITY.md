# Security Policy

## Supported Versions

The security fixes are made for the latest release only.

## Reporting a Vulnerability

Please don't open a public issue. Report the vulnerability privately with [Github's security advisories](https://github.com/PiercingXX/devdash/security/advisories/new), with the steps to reproduce it and its impact.

You'll get an answer within a week. Once the vulnerability is fixed and released, the advisory is published with credit to you, unless you prefer otherwise.

DevDash handles credentials: Google keyfiles, Github tokens, SSH agent keys, and the headers of the `json` widgets. Never paste them in issues or pull requests.
